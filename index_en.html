14 PENDING TRANSACTIONS & REVERSAL RECOVERY

Resilient Network Outage Protection Zero Merchant Capital Loss

The biggest hazard in POS retail is connection timeout mid-transaction. Theqa Pay incorporates an automated state machine to detect, hold, verify, and reverse stalled transactions.

1️⃣
Detection & Local Caching
If network disconnects mid-flight, transaction state is held locally in Room DB tagged as **PENDING_RECOVERY**.
2️⃣
Smart Startup Intercept
Upon connection recovery or app launch, the merchant is routed directly to the pending audit screen, blocking new debits until resolved.
3️⃣
Automated Status or Reversal
Server is queried: if completed, receipt prints; if failed, balance is refunded instantly with an official reversal slip.
